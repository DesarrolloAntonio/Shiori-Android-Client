<b>Vor der Installation: Diese App benötigt einen Shiori-Server.</b> Sie ist ein Client für Shiori, den Open-Source-Lesezeichen-Manager, den Sie selbst hosten (auf einem Computer, einem NAS oder einem VPS). Allein funktioniert sie nicht, und es gibt kein Konto zum Registrieren: Sie melden sich an Ihrem eigenen Server an, ab Version 1.7. So richten Sie einen ein: https://github.com/go-shiori/shiori/blob/master/docs/Installation.md

Ihre gesamte Bibliothek liegt auf dem Gerät, sodass die Liste, die Tags und jeder gespeicherte Artikel auch ohne Verbindung verfügbar sind. Was Sie offline ändern (hinzufügen, bearbeiten, löschen, eine neue Kopie einer Seite anfordern), wird gesammelt und gesendet, sobald Ihr Server wieder erreichbar ist.

<b>Funktionen</b>

• <b>Aus jeder App speichern</b>: Teilen Sie eine Seite aus dem Browser, und sie landet in Ihrer Bibliothek, ohne die App zu öffnen.
• <b>Offline lesen</b>: Artikel werden als sauberer, lesbarer Text gespeichert, ohne die Website drumherum.
• <b>Offline arbeiten, später synchronisieren</b>: Änderungen ohne Verbindung werden gesendet, sobald der Server wieder antwortet.
• <b>Suche</b> in Titeln, Auszügen und URLs direkt auf dem Gerät, also auch offline.
• <b>Tags</b>: Liste nach Tag filtern, Tags umbenennen oder löschen oder einen Tag aus der Liste ausblenden.
• <b>Mehrfachauswahl</b>: mehrere Lesezeichen auf einmal taggen, neu zwischenspeichern oder löschen.
• <b>EPUB</b>: das E-Book, das Ihr Server aus einer Seite erstellt hat, herunterladen und in Ihrer Lese-App öffnen.
• <b>Smartphones, Tablets und Foldables</b>: Die Liste nutzt so viele Spalten, wie der Bildschirm fasst, und auf großen Bildschirmen kann der Artikel daneben geöffnet werden.
• <b>Material 3</b>, hell und dunkel.

<b>Voraussetzungen</b>

• Ein erreichbarer Shiori-Server, Version 1.7 oder neuer.
• Android 8.0 oder neuer.

Dies ist eine unabhängige App und stammt nicht vom Shiori-Projekt. Sie ist Open Source unter der Apache-2.0-Lizenz: https://github.com/DesarrolloAntonio/Shiori-Android-Client
